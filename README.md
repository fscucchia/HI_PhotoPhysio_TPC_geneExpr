#Contrasting thermal tolerance in corals emerges from temperature-induced gene network rewiring and isoform switching

This electronic notebook provides the scripts and data for the physiology, thermal performance, gene expression and isoform switching analyses of the Hawaiian corals _Montipora capitata_, _Pocillopora acuta_ and _Porites compressa_.
